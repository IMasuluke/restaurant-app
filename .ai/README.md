# AI Context Index

This folder contains focused context files for coding agents. Load only the files relevant to the task.

## Folders

- `architecture/`: project shape, module boundaries, data flow, and feature behavior.
- `conventions/`: coding, Android, documentation, and verification conventions.
- `skills/`: task-oriented workflows agents can follow.

Start with `AGENTS.md` at the repository root for context-loading rules. `CLAUDE.md` is a symlink to `AGENTS.md`.
